# accessible-ml
This is a github repository where i document my idea of making a software which makes machine learning accessible to someone who doesn't specialize in computer programming. Please feel free to better the code or give feedback. Thank You.



We'll start by planning what are the requirements for this project.
In simpler terms we require a FrontEnd and backend.

For FrontEnd
We shall require a simple enough but smooth UI(User Interface). We can create the ui by using javascript reactnative.

For BackEnd

We shall require a sofisticated Backend which handles importing of datasets, normalization of it and making sense of it at the end. 
later we also have to connect an ui element where the user gets to draw on a panel their preferred dataset for example a number data set and get their accuracy and prediction of what could the character drawn mean.


USER EXPERIENCE

Chooses or imports dataset, chooses way of processing and compares methods of processing by judging data provided by us, uses prediction panel to predict user-drawn characters.
